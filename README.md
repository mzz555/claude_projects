## ✈️ 雷霆战机 v4.1 (plane/)

参考雷霆战机风格的纵版射击游戏。画布 640×800，自动攻击。

### 操作键

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → / W A S D | 移动英雄机 |
| B | 呼叫支援（消耗1次支援次数） |
| P | 暂停 / 继续 |

**敌机出现等级：**
- Lv.1：侦察机 / 战斗机 / 拦截机
- Lv.2+：+ 巡洋舰 / 精英机
- Lv.3+：+ 轰炸机
- Lv.5+：+ 母舰（定期释放侦察机子机）

**Boss 三阶段：**
```
HP 100%→50%  Phase 1：5颗扇形子弹（直射）
HP  50%→25%  Phase 2：5颗追踪弹幕（扇形朝向玩家）
HP  25%→ 0%  Phase 3：10颗全向旋转 + 1颗超速追踪弹
```

Boss 出现时清空场上所有普通敌机和子弹。

```
         │  每300帧自动触发：
         │  充能60帧（炮口光晕动画）→ 发射180帧（紫色光柱）
```

### 道具系统

场上同时最多存在 **3个** 道具，**同类型不重复**。
**火力道具爆率 20%**，拾取后 **5秒冷却**再掉落下一个。

| 道具 | 颜色 | 效果 |
|------|------|------|
| 火力升级 ⊕（随等级变色） | 绿→黄→橙→红→紫→青 | 火力 +1 级，或激活/续期超频 |
| 护盾 ◈ | 紫色 | 恢复满盾（容量100） |
| 支援 ✈ | 绿色 | +1次支援次数（上限5） |
| 加命 ♥ | 粉红 | +3 HP |
| 加速 ▶ | 青色 | 移速×1.5，持续6s |

**掉落逻辑：** 火力(20%，有冷却) → 加命(30%，HP不足时) → 支援(28%，次数<3时) → 随机

---

### 支援系统（B键）

- 默认3次，最多5次，可通过支援道具补充
- 召唤2架绿色僚机各伴飞1架，自动射击，HP各8
- 持续12秒（720帧），可被敌机子弹击落
- 僚机跟随英雄机左右各65px

```
          ↓
     击败 Boss → 升关
          ↓
     关卡越高：敌机更密、种类更多、火力更强
```

| 关卡 | 基础生成间隔 | 新增敌机类型 |

| 3-4 | 21-29帧 | + 轰炸机 |
| 5+ | 14帧(下限) | + 母舰 |
