# Claude Projects — 小游戏合集

用 Claude Code 辅助开发的网页小游戏集合。

## 项目结构

```
ccTest/
├── snake/          # 贪吃蛇游戏
│   ├── index.html
│   ├── style.css
│   └── game.js
└── plane/          # 雷霆战机 —— 飞机大战
    ├── index.html
    ├── style.css
    └── game.js
```

## 游戏列表

### 🐍 贪吃蛇 (snake/)
经典贪吃蛇玩法。

**操作：** 方向键控制移动

---

### ✈️ 雷霆战机 (plane/)
参考雷霆战机风格的纵版射击游戏。

**操作：**
| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → / WASD | 移动 |
| B | 呼叫支援 |
| P | 暂停 |

> v3.0 已改为**自动攻击**，无需按空格射击

**特性：**
- 地图 640×800，活动范围大幅扩展
- 英雄机 **30 条命**，生命值数字显示
- **自动攻击**，无需手动按键射击
- **7 种敌机**：侦察机 / 战斗机 / 巡洋舰 / 拦截机 / 轰炸机 / 精英机 / 母舰 + Boss
- Boss 三阶段弹幕变化（散射→追踪→全向旋转）
- 道具系统：双倍子弹 / 护盾 / 支援 / 加命 / 加速
- **B 键 = 呼叫支援**：默认 3 次，召唤 2 架绿色僚机（HP×2）伴飞 12 秒，自动射击，可被击落
- 母舰可定期释放侦察机子机
- 丰富过渡特效：屏幕震动 / 屏幕闪光 / 敌机入场粒子 / 升关辉光 / 玩家登场动画
- 粒子爆炸特效（6 种规模）
- Web Audio API 音效
- 关卡系统（每关打 Boss 升级，难度递增）
- 三档难度
